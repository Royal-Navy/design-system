# Development

## Installation

To install and save to your project's package.json dependencies, run:

<Source
  dark
  code={`npm install @royalnavy/fonts @royalnavy/react-component-library styled-components`}
/>

_`styled-components` is a required peer dependency and is installed with the above command._

## Quick start

Here's a quick example to get you started:

<Source dark code={`import React from 'react'
import { createRoot } from "react-dom/client";
import '@royalnavy/fonts'
import { GlobalStyleProvider, Button } from '@royalnavy/react-component-library'

const rootElement = document.getElementById("root");
const root = createRoot(rootElement);

function App() {
return (
<GlobalStyleProvider>
<Button variant="primary">
Hello, World!
</Button>
</GlobalStyleProvider>
)
}

root.render(<App />)`} />

---

## Dark mode (experimental)

Dark mode is off by default. To opt in, pass the dark theme and enable colour modes on the provider:

<Source dark code={`import { darkTheme } from '@royalnavy/design-tokens'
import { GlobalStyleProvider } from '@royalnavy/react-component-library'

<GlobalStyleProvider theme={darkTheme} unstable_colorModes>
  <App />
</GlobalStyleProvider>`} />

The provider declares the colours as `--rn-color-*` CSS variables on `:root`, so render one provider per page when colour modes are enabled. To make your own styles follow the colour mode, use `themeColor` from `@royalnavy/design-tokens` instead of `color`. This API is unstable and may change in a minor release.
